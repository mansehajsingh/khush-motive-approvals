# Khush Motive Approvals

Welcome to the official **Khush Motive Approval System™**.

This repository is the single source of truth for determining which motives
are worthy of Khush's time.

## How It Works

Have a motive?

Don't just announce it. **Propose it.**

1. Fork this repository.
2. Create a new motive proposal.
3. Open a Pull Request.
4. Wait for Khush to review it.
5. If approved, the motive is officially sanctioned.
6. If closed, the motive has been rejected by management.

> No motive shall proceed without proper approval.

## Approval Status

| Status | Meaning |
|---|---|
| 🟡 Open | Under consideration |
| 🟢 Approved | Khush is down |
| 🔴 Closed | Khush is not down |
| 🟣 Draft | We are cooking |
| ⚠️ Changes Requested | Make the motive better |

## The Golden Rule

**If Khush approves the PR, we do the motive.  If not... do the math.**
